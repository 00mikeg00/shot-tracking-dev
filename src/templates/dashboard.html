Help — What do I do?

  1. Find the class and assignment on this page.
  2. Click on Open

    3. This will start maya and open or start your assignment. NO need to double click on the icon on the desktop!

    In Maya, CTL+S will save the file on the server. No need to save Locally!

    Incremental Save will bump up a version. It will duplicate what you have, just called a higher version.

  1. Click on the Black Filmstrip to make a movie.
  2. Submit assignment - this will submit the movie to the server to be graded.

    3. MOVIE FOR YOU - will create a movie in C:/Cincy/Movies with your assignment and name on it.

  1. Once submitted, the status of your assignment will change to Submitted. That will tell your instructor that the shot is ready to be reviewed.
  2. Once reviewed, you MAY have a video review. If you do, it will show up under the assignment. The latest TWO reviews will show up.
  3. It will also say that there is a grade and a retake. It is up to you to either change the status to Graded, OR to make changes to the shot and resubmit.
  1. Click on the Steps button. This will open the Planning section.
  2. Click on Submit Planning
  3. Upload Drawings and Vid Ref in the right places.
  4. Click on Open X-Sheet to open the X-sheet
  5. Submit Planning will only allow you to submit if all three of the aspects have been filled (drawings, vid ref, x-sheet)

The length is determined by the shot. If you need more frames:

Add more frames at the bottom.

The columns are this:

  1. Words - if you have a dialog shot. This is where each word goes. Just one word at a time.
  2. Sounds - if you have a dialog shot. This is where the phonemes go. You can also add symbols for holds, accents, ups, and downs.
  3. Blocking - type in the frame where your poses are. Simple descriptions are best.
  4. Breakdown/Tween - you can add where your breakdowns and tweens are.
  5. Notes - any notes you may have. This keeps the Blocking column simpler.

    6. You may add more columns for Blinks, Hands, Tails, Legs, and Cameras, if you like.

    Save will save the x-sheet.

    Share for feedback will send it to the markup to be graded - this is optional. Submitting your planning only requires that the x-sheet has been saved with something on it, not that you've shared it.

  1. Most of the upper level assignments have different steps to them - Planning, Blocking, Blocking Plus, and Polish
  2. Planning is done the same way as the Planning Alone assignment.

    3. Once your assignment is submitted in a step, you can move on to the next step.

  3. In MAYA, make sure you save the step using the GAA Save button (second from left on the GAA shelf).

    4. This will only work with assignments that have multiple steps.

  4. If you want to move on, you can lock the step and save the new step.
  5. You can always go back to an older step by using the GAA Open button (third from left on the GAA shelf).

    6. this will allow you to unlock and open any step.

    BE CAREFUL DOING THIS as you may LOSE WORK!
